J.A.R.V.I.S. — приложение для Android
=====================================

Что здесь:
  JARVIS-v1.2.apk — готовое приложение (Android 7.0+, лучше 8.0+)
  source/         — исходники: MainActivity.java (Java-мост), NotifReceiver.java
                    (напоминания), патчи UI (слои 1-4), AndroidManifest.xml,
                    иконки, скрипты сборки

Что нового в v1.2 — УВЕДОМЛЕНИЯ И НАПОМИНАНИЯ:
  - Настоящие системные уведомления: JARVIS напоминает о делах даже если
    приложение закрыто (будильники AlarmManager + канал уведомлений).
  - «напомни через 5 минут позвонить маме» — разбор длительности: цифры,
    слова («пять», «полчаса»), сек/мин/часы.
  - «напомни в 15:30 забрать посылку», «напомни завтра в 7 утра принять
    таблетки» — время с переходом на завтра, если оно уже прошло.
  - «таймер на 10 минут» / «таймер 90 секунд» — таймер с уведомлением.
  - «покажи напоминания» — список активных; «отмени напоминание 2» — отмена
    по номеру; «отмени напоминания» — отмена всех.
  - «тест уведомлений» или чип 🔔 в шапке — проверка в один тап.
  - Сработавшее напоминание: heads-up уведомление + вибрация + JARVIS
    озвучивает его, если приложение открыто. Тап по уведомлению открывает
    JARVIS.
  - На Android 13+ приложение попросит разрешение на уведомления при первом
    запуске (это стандартный системный диалог).

Установка:
  Способ 1 — прямо с телефона, через приложение GitHub (самый простой):
    1. Открой репозиторий jarvis в приложении GitHub.
    2. Вкладка/раздел «Releases» → релиз «J.A.R.V.I.S. для Android — v1.2».
    3. Тапни JARVIS-v1.2.apk → «Скачать» (если приложение спросит — «Download»).
    4. Открой файл из шторки уведомлений или «Файлы» → Downloads.
    5. Дальше — как в способе 2, начиная с шага 2.

  Способ 2 — через браузер или с компьютера:
    1. Скачай JARVIS-v1.2.apk на телефон и открой его.
    2. Android предупредит про установку из неизвестного источника — разреши
       (стандартно для APK вне Play Market).
    3. При первом запуске разреши микрофон и уведомления — это голосовой ввод
       и напоминания.
    4. Реактор загорится, JARVIS поздоровается.

  Обновление с v1.0/v1.1: просто установи новый APK поверх старого — подпись
  та же, настройки, ярлыки и напоминания сохранятся.

Голос:
  - Тап по микрофону → диалог Google «Слушаю, сэр…» → фраза выполняется
    как команда (ru-RU; в режиме «authentic» — en-GB).
  - Ответы озвучивает системный TTS. Режим «ДЖАРВИС · RU» / «JARVIS · EN»,
    скорость и высота — в ⚙ Настройки, вкладка «Голос».

Команды телефона:
  напомни через 5 минут позвонить маме — напоминание с уведомлением
  напомни в 15:30 забрать посылку — напоминание ко времени
  напомни завтра в 7 утра принять таблетки — на завтрашнее утро
  таймер на 10 минут / таймер 90 секунд — таймер
  покажи напоминания — активные напоминания и таймеры
  отмени напоминание 2 / отмени напоминания — отмена одной / всех
  тест уведомлений — проверка уведомлений (или чип 🔔 в шапке)
  громкость 40 / громче / тише / мут — громкость мультимедиа
  включи фонарик / выключи фонарик — вспышка камеры
  батарея / сколько заряда — заряд и статус
  запусти ютуб / телеграм / фотошоп / … — ЛЮБОЕ установленное приложение
    по названию (умный поиск) или ярлык из ⚙ Настройки
  открой настройки / вай-фай / блютуз — экраны настроек
  включи музыку / следующий трек / предыдущий трек — плеер
  «выключи компьютер» и другие ПК-команды — вежливо отклоняются

ИИ-мозг (по желанию):
  Кнопка «ИИ: ВЫКЛ» в шапке → вставь API-ключ (тот же, что в jarvis.conf
  ПК-версии — подойдёт любой OpenAI-совместимый провайдер: base URL + модель
  + ключ) → ВКЛ / ВЫКЛ → СОХРАНИТЬ.
  Непонятые фразы будут уходить нейросети, а метки [[OPEN:…]] / [[RUN:…]] /
  [[SEARCH:…]] она исполняет как действия на телефоне.

Важно:
  - Приложение ничего не отправляет наружу, кроме запросов к твоему
    ИИ-провайдеру, если включен ИИ-мозг.
  - Серверы и порты не нужны — всё работает локально внутри приложения.
  - Напоминания хранятся только на телефоне (SharedPreferences) и живут
    до перезагрузки устройства.
