J.A.R.V.I.S. — приложение для Android
=====================================

Что здесь:
  JARVIS-v1.1.apk — готовое приложение (Android 7.0+, лучше 8.0+)
  source/         — исходники: MainActivity.java (Java-мост), патчи UI
                    (слои 1-3), AndroidManifest.xml, иконка, скрипты сборки

Что нового в v1.1:
  - Запуск ЛЮБЫХ установленных приложений по названию: «запусти ютуб»,
    «включи телеграм», «запусти фотошоп» — умный поиск: псевдонимы RU/EN →
    точное совпадение по названию приложения → вхождение → нечёткий поиск.
    Свой список ярлыков в ⚙ Настройки по-прежнему приоритетный.
  - Починен запуск на Android 11+: в манифест добавлен <queries>, без него
    система скрывала приложения и запуск мог вести в Play Market.
  - Интерфейс одинаково удобен в портрете и в ландшафте: в ландшафте —
    три колонки и компактная шапка, в портрете — крупное поле ввода и
    высокий журнал; длинные строки больше не растягивают вёрстку.

Установка:
  Способ 1 — прямо с телефона, через приложение GitHub (самый простой):
    1. Открой репозиторий jarvis в приложении GitHub.
    2. Вкладка/раздел «Releases» → релиз «J.A.R.V.I.S. для Android — v1.1».
    3. Тапни JARVIS-v1.1.apk → «Скачать» (если приложение спросит — «Download»).
    4. Открой файл из шторки уведомлений или «Файлы» → Downloads.
    5. Дальше — как в способе 2, начиная с шага 2.

  Способ 2 — через браузер или с компьютера:
    1. Скачай JARVIS-v1.1.apk на телефон и открой его.
    2. Android предупредит про установку из неизвестного источника — разреши
       (стандартно для APK вне Play Market).
    3. При первом запуске разреши микрофон — нужен для голосовых команд.
    4. Реактор загорится, JARVIS поздоровается.

  Обновление с v1.0: просто установи новый APK поверх старого — подпись та
  же, настройки и ярлыки сохранятся.

Голос:
  - Тап по микрофону → диалог Google «Слушаю, сэр…» → фраза выполняется
    как команда (ru-RU; в режиме «authentic» — en-GB).
  - Ответы озвучивает системный TTS. Режим «ДЖАРВИС · RU» / «JARVIS · EN»,
    скорость и высота — в ⚙ Настройки, вкладка «Голос».

Команды телефона:
  громкость 40 / громче / тише / мут — громкость мультимедиа
  включи фонарик / выключи фонарик — вспышка камеры
  батарея / сколько заряда — заряд и статус
  запусти ютуб / телеграм / фотошоп / … — ЛЮБОЕ установленное приложение
    по названию (умный поиск) или ярлык из ⚙ Настройки
    (цель вида pkg:имя.пакета или URL)
  открой настройки / вай-фай / блютуз — экраны настроек
  включи музыку / следующий трек / предыдущий трек — плеер
  «выключи компьютер» и другие ПК-команды — вежливо отклоняются

ИИ-мозг (по желанию):
  Кнопка «ИИ: ВЫКЛ» в шапке → вставь API-ключ (тот же, что в jarvis.conf
  ПК-версии — подойдёт любой OpenAI-совместимый провайдер: base URL + модель
  + ключ) → ВКЛ / ВЫКЛ → СОХРАНИТЬ.
  Непонятые фразы будут уходить нейросети, а метки [[OPEN:…]] / [[RUN:…]] /
  [[SEARCH:…]] она исполняет как действия на телефоне — [[RUN:ютуб]] теперь
  находит приложение по названию.

Важно:
  - Приложение ничего не отправляет наружу, кроме запросов к твоему
    ИИ-провайдеру, если включен ИИ-мозг.
  - Серверы и порты не нужны — всё работает локально внутри приложения.
