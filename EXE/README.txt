J.A.R.V.I.S. — готовое приложение (Windows x64)
================================================

Что здесь:
  jarvis.exe          — основное приложение: окно JARVIS (WebView2) + сервер
  jarvis-server.exe   — запасной вариант без окна: сервер + интерфейс в браузере
  shortcuts.json      — ярлыки (roblox, discord, spotify и т.д.), должны лежать рядом с exe

Как запустить:
  1. Скачай ВСЮ папку EXE целиком (exe без shortcuts.json не увидит ярлыки).
  2. Двойной клик по jarvis.exe — откроется окно J.A.R.V.I.S.
     Нужен WebView2 Runtime (на Windows 10/11 уже встроен; если нет —
     поставится с https://developer.microsoft.com/microsoft-edge/webview2/).
  3. Если окно не открылось — запусти jarvis-server.exe:
     поднимется сервер и откроется браузер с тем же интерфейсом.

Важно:
  - Порт 8000 должен быть свободен (сервер живёт на http://localhost:8000).
  - Закрыть программу: закрыть окно (или консоль у server-версии).
  - exe собран из папки GO этого репозитория, ничего не качает и не отправляет наружу.
